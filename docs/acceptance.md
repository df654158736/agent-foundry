# v0.1.0 验证记录

本版定位为开发者预览。源码携带可复演的验证入口，模型配置由使用方提供。

| 检查 | 方法与判据 |
| --- | --- |
| 环境与发行物 | 在独立目录解压源码 ZIP，用 uv 0.12.2、CPython 3.12.13 和 uv.lock 在全新虚拟环境安装，核对 ZIP 的 SHA-256 |
| 单业务隔离 | 初始化空项目与班次示例，确认新项目只读自己的工具和系统提示词。库存场景通过 OpenAI 客户端的受控 HTTP transport 发起两次协议调用，核验工具参数、回执和最终正文 |
| Skill 与多轮 | 运行班次 fixture，检查模型输入的实际工具 schema、业务 Skill 文件读取回执、第二轮日期修改及站点保持 |
| 纠错与相邻保护 | 故障基线按站点查班次，遗漏日期；候选同时核对站点和日期。shift 由 FAIL 到 PASS，missing 维持 PASS。原问、脚本模型与独立判据保持相同 |
| 证据完整性 | 各 attempt 独立保留。使用 AgentGauge 0.4.0.dev10 的 Trace.model_validate_json 对示例的交换文件做格式校验 |
| 升级 | 同版本并行迁移演练保留业务资产、权限边界和原项目，框架文件被定制时阻止静默覆盖。下一版发布时仍须真正进行跨版本测试 |

复演：在发行目录执行 README 中的 unittest 和 scripts.prove_iteration。受控模型负责驱动场景，不产生可用于声称真实模型自主性的证据。真实提供商的稳定性、复杂授权写操作、跨进程业务恢复、全新 Codex 宿主的 reviewer 自动发现和独立开发者的接入耗时仍须分别验收。
