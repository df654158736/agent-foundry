# 智能体评测证据台账

[主 Skill](../SKILL.md) 定义取证与归因流程，本文件只提供记录结构。公共环境与冻结契约记录一次；按用例不同截面补差异，不机械建无关字段。

| 字段 | 记录内容 |
|---|---|
| 用例 | 稳定 ID、冻结原始输入/期望、版本/哈希、目标/禁止行为、前置及预设用户选择 |
| 环境 | 正常入口、真实身份/权限/作用域、代码与制品、实际运行配置与依赖 |
| 关联标识与阶段 | case、run、thread、turn、trace、span、task、request ID、责任方法和时间窗 |
| 输入与决策 | 原文、真实模型可见上下文/schema/Skill、状态/候选、决策所有者、依据和原始提案 |
| 产物及消费者 | 工具回执、错误、编译/冻结/实发、完整中间产物或脱敏引用；下游实际读取及状态/副作用 |
| 结果核验 | 独立 Oracle、范围等价与数值/集合一致、用户可见正文与作者、事实引用、交互及续接 |
| 预期/实际 | 精确匹配或允许波动字段、首次差异、责任证据 |
| 结论与证据 | 冻结评分、业务、交互、信息供给、模型、Harness、基础依赖分别判定；证据等级、未验范围、可打开原始证据/脱敏链接 |

## 金标适用性记录

| 字段 | 必需证据 |
|---|---|
| 目的及权威契约 | 当前回归或目标能力验收；业务结果、过程或负路径；有效需求/Spec、版本与确认状态 |
| 业务目标与合法路径 | 原始目标、全部约束、实际路径；哪些具体字段/编码、工具或顺序有独立契约依据 |
| 分层前置 | 元数据准入、可过滤、唯一识别、索引、绑定、接口、数据、权限、环境的就绪证据与 owner |
| Oracle 与断言 | 独立真值来源、每项强制期望的依据、允许变化 |
| 适用性结论 | 可执行、前置阻塞、契约或用例待确认；限定到受影响路径/用例 |

判定：源数据存在不等于接口支持；一层不支持不代表其他合法路径不存在。业务结果金标不能因符合契约的拒答判成功，负路径按实际错误/拒答契约验收。合法前置齐备而实际违约按首次责任定位；已承诺未实现记能力缺口，前置不足记阻塞，契约/断言冲突先提出质疑。禁止用未经授权的查库、猜测或映射补偿缺项；经确认修改基线保留原版本和未覆盖能力，不混算新旧分数，也不把移除题算修复。

## 规范或用例质疑记录

| 字段 | 内容 |
|---|---|
| 对象/冲突 | Spec 条款、金标、fixture、Oracle 原文及版本，在已确认目标/契约下的具体矛盾 |
| 实证/归因 | trace、日志、只读数据、最小复现；为什么是契约/评测而非普通实现缺陷 |
| 影响 | 用户、业务、安全、兼容性及评测可信度 |
| 方案/推荐 | 保留或修订设计、用例、正规数据等可行方案及取舍 |
| 待确认与状态 | 需要人类决定的明确问题；待讨论、已确认、已拒绝、已同步及影响范围 |
