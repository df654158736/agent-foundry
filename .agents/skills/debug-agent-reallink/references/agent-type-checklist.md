# 不同智能体的附加检查项

只读取并使用当前任务相关的小节。

## 工具调用型智能体

- 工具选择、schema、参数纠偏、调用顺序和失败回退。
- 禁止工具是否被真正从运行时移除，而非仅从 prompt 隐藏。
- 工具结果是否被完整消费，错误是否被模型误当作成功。

## RAG 与知识问答智能体

- 查询改写、索引版本、召回层、候选、排序分数和权限过滤。
- 引用是否确实支持对应主张，是否出现检索到但未使用或未检索却引用。
- 空召回、知识冲突、过期内容和答案拒绝是否符合策略。

## 工作流与状态机智能体

- 节点、边、分支条件、循环上限、重试、暂停恢复和终止状态。
- checkpoint、幂等键、跨轮状态合并和并发竞争。
- 每个节点的实际输入输出是否符合图定义。

## 多智能体系统

- 任务由谁拆分，为什么委派给该子智能体。
- 传递了哪些上下文，是否泄漏答案或缺少关键约束。
- 子结果如何校验、冲突如何仲裁、失败如何重派或收口。
- 总调用预算、并发、重复劳动和责任归属是否清晰。

## 代码智能体

- 文件与仓库规则发现、影响面分析、修改授权和工作区保护。
- 补丁是否针对根因，测试是否真实覆盖失败路径。
- 构建、静态检查、回归、运行验证及提交/MR 范围。
- 命令副作用、秘密信息和破坏性操作防护。

## 数据分析与查询智能体

- 口径、时间、过滤、分组、实体、权限和默认值来源。
- 计划/查询结构、实际 SQL/OQL/API 参数、原始行与聚合结果。
- 空集、零值、缺数据、过滤失败和权限不可见必须区分。

## 浏览器与操作型智能体

- 页面状态、元素定位、动作前后截图/DOM、重定向和会话身份。
- 写操作前的目标、范围、确认与可恢复性。
- 网络请求、页面反馈和后台真实状态三方是否一致。

## 对话、客服与任务助理

- 意图、槽位、上下文继承、澄清策略和用户否定表达。
- 政策边界、转人工、承诺内容和跨轮一致性。
- 回答是否解决用户目标，而不是只满足表面话术。

## 规划与自治智能体

- 目标分解、计划更新、完成条件和阻塞判断。
- 是否越权扩展目标，是否在有安全路径时过早停止。
- 长任务中的状态压缩、恢复、监控和资源预算。
